# 账号登录与安全

## 登录和重新进入应用

使用管理员提供的工号、密码登录。下次打开应用时，清眸会验证上次登录状态；若服务器暂时不可连接，可以重试连接或切换账号、服务器。登录状态失效时，需要重新登录。

没有账号或忘记密码，请联系管理员。清眸不提供自助注册。

## 修改密码

1. 打开【我的 → 账号安全】。
2. 输入至少 6 位的新密码，再输入一次确认。
3. 点击【保存】。

![账号安全页的新密码与确认输入框](/screenshots/20260929/36-account-security.webp)

修改成功后，其他设备上原有的登录状态可能失效，届时使用新密码重新登录。

## 退出登录

在【我的】页面点击【退出登录】。应用会清除本机的登录状态，之后需要再次输入工号和密码。

退出登录也会取消清眸的调查通知、清空桌面调查卡片的本地展示，并恢复禁止截图和录屏。应用默认使用隐私窗口保护画面；用户可在【我的 → 账号安全 → 截图与录屏】验证当前账号密码后更改权限，具体见[个人中心](09-profile-and-settings.md#截图与录屏权限)。文档中的原有界面图由临时截图构建采集。

## 常见情况

| 看到的情况 | 可以怎么做 |
| :--- | :--- |
| 登录页显示服务器未连接 | 检查网络，重试连接；使用自建服务时核对地址。 |
| 启动时停在连接页面 | 点击【重试连接】。不要把空白页面当作已登录。 |
| 账号被停用或密码已由管理员重置 | 联系管理员确认账号状态或获取新密码，然后重新登录。 |
| 小组列表为空 | 到【我的消息】接受邀请，或在【我的】新建小组；详见[小组协作](04-group-collaboration.md)。 |

小组邀请同样从【我的 → 我的消息】处理，具体步骤见[小组协作](04-group-collaboration.md)。
