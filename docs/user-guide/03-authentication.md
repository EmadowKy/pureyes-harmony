# 03-账号认证与安全设置

在 Pureyes 系统中，身份认证与账号安全采用了严格的凭据校验标准与服务端黑名单熔断机制，保障安防监控数据的隐私与安全。

---

## 1. 登录认证机制

- **工号认证**：本系统使用全局唯一的工号作为登录凭据标识。
- **密码安全**：服务端保存密码哈希，不保存明文。使用自定义服务器时应配置 HTTPS，避免在网络传输中暴露登录凭据。
- **安全凭据状态保存**：成功登录后，访问令牌、刷新令牌及所用服务器地址保存在设备安全存储中。再次进入应用时会先向该服务器核验账号；访问令牌过期时尝试续期。服务器不可达时停留在可重试的连接页，不会直接进入空白工作台。更换服务器或旧版本未保存服务器绑定信息时需要重新登录。
- **系统输入辅助**：登录输入框标注了账号和密码类型，可使用系统提供的输入建议；应用自身不会保存明文密码。

---

## 2. 修改密码 (账号安全)

为保障账号安全，建议定期修改登录密码：

1. 进入底部导航栏【我的】页。
2. 点击【账号安全】独立功能入口。
3. 在弹出的修改密码界面中，依次输入：
   - **原密码**：当前使用的登录密码。
   - **新密码**：至少 6 位的新密码。
   - **确认新密码**：再次输入新密码进行确认。
4. 点击【提交修改】。系统校验成功后将提示重新登录。

> [!IMPORTANT]
> 修改密码成功后，系统为了保障安全性，会强制作废当前账号在其他设备上的旧登录凭据，您需要在其他设备上使用新密码重新登录。

---

## 3. 自动登出与安全熔断

为了应对设备丢失或账号异常情况，Pureyes 内置了主动与被动的安全保护机制：

| 触发场景 | 系统行为 | 说明 |
| :--- | :--- | :--- |
| **主动登出** | 点击【我的】->【退出登录】 | 清除本地登录凭据，服务器记录凭据废弃状态。 |
| **账号被停用** | 管理员在后台停用该用户 | 该账号再次发起访问时直接拒绝，并提示账号已被停用。 |
| **密码被重置** | 管理员初始化该账号密码 | 该账号旧凭据立即作废，要求用户用初始密码重新登录。 |
| **凭据自然到期** | 访问令牌过期 | 启动或回到前台时尝试用刷新令牌续期；刷新令牌也失效则回登录页。 |
| **服务器暂不可达** | 启动或回到前台时无法验证会话 | 保留本地凭据，显示重试连接与切换账号或服务器入口。 |

---

## 4. 我的消息中心

在【我的】页面中，点击【我的消息】，可以查看系统推送给您的重要安全与团队通知：
- 邀请加入小组通知。
- 账号角色变更通知（如升级为管理员）。
- 系统安全告警或密码修改提醒。
