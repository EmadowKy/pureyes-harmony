# 03-账号认证与安全设置

在 Pureyes 系统中，身份认证与账号安全采用了严格的凭据校验标准与服务端黑名单熔断机制，保障安防监控数据的隐私与安全。

---

## 1. 登录认证机制

- **工号认证**：本系统使用全局唯一的工号作为登录凭据标识。
- **密码安全**：密码在传输与数据库存储过程中经过哈希加密算法处理，严格禁止明文存储。
- **安全凭据状态保存**：成功登录后，系统会自动保存安全凭据状态，在设备未主动退出登录前，再次进入应用无需重复输入密码。
- **鸿蒙密码保管箱与指纹/人脸一键填充**：应用深度集成了 HarmonyOS 密码保管箱原生特性（Password Vault）。
  - **登录后问询保存**：首次成功登录后，系统底层会询问是否将账号密码保存至鸿蒙密码保管箱。
  - **生物特征一键填充**：下一次登录时，点击输入框软键盘上方会自动弹出保存的凭据卡片，通过指纹或人脸核验后即可自动填充秒级登录。

---

## 2. 修改密码 (账号安全)

为保障账号安全，建议定期修改登录密码：

1. 进入底部导航栏【我的】页。
2. 点击【账号安全】独立功能入口。
3. 在弹出的修改密码界面中，依次输入：
   - **原密码**：当前使用的登录密码。
   - **新密码**：至少 6 位的新密码。
   - **确认新密码**：再次输入新密码进行确认。
4. 点击【提交修改】。系统校验成功后将提示重新登录。

> [!IMPORTANT]
> 修改密码成功后，系统为了保障安全性，会强制作废当前账号在其他设备上的旧登录凭据，您需要在其他设备上使用新密码重新登录。

---

## 3. 自动登出与安全熔断

为了应对设备丢失或账号异常情况，Pureyes 内置了主动与被动的安全保护机制：

| 触发场景 | 系统行为 | 说明 |
| :--- | :--- | :--- |
| **主动登出** | 点击【我的】->【退出登录】 | 清除本地登录凭据，服务器记录凭据废弃状态。 |
| **账号被停用** | 管理员在后台停用该用户 | 该账号再次发起访问时直接拒绝，并提示账号已被停用。 |
| **密码被重置** | 管理员初始化该账号密码 | 该账号旧凭据立即作废，要求用户用初始密码重新登录。 |
| **凭据自然到期** | 超出系统默认安全有效期 | 客户端发起操作时收到到期提醒，自动跳转至登录页。 |

---

## 4. 我的消息中心

在【我的】页面中，点击【我的消息】，可以查看系统推送给您的重要安全与团队通知：
- 邀请加入小组通知。
- 账号角色变更通知（如升级为管理员）。
- 系统安全告警或密码修改提醒。
