# 快速开始

按以下顺序登录、选择小组、打开监控与工作区。

---

## 1. 登录

- 在鸿蒙手机上打开清眸，等待登录页完成服务器连接检测。
- 输入管理员提供的工号和密码，点击【进入工作台】。目前不支持在登录页自行注册账号；没有账号请联系管理员。
- 登录页的【使用说明】可以打开在线文档。若团队使用自建服务，可在登录页切换服务器地址并重新检测连接。

登录后也能从【我的】→【使用说明】再次打开本文档。

---

## 2. 选择小组

应用会加载当前账号已加入的小组。尚未选择小组时，监控、工作区与通讯录不会显示。点击页面中的小组入口，或从顶部选择器选择小组。

如果没有可选小组，首页会提示进入【我的】。你可以[新建小组](04-group-collaboration.md#1-创建小组)，或者到【我的消息】接受组长的邀请；完成后选择小组即可继续。

## 3. 找到功能

选定小组后，底部出现四个入口：

- **监控**：查看摄像头、实时画面和录像回放。详见[监控与回放](05-live-monitoring.md)。
- **工作区**：截取视频片段、查看人脸线索、向调查 Agent 提问。详见[工作区](06-workspace-management.md)与[调查问答](07-ai-multimodal-qa.md)。
- **小组**：查看成员；组长可以邀请成员。详见[小组协作](04-group-collaboration.md)。
- **我的**：查看邀请、修改资料与密码、设置模型配置；管理员还能管理账号。详见[个人中心](09-profile-and-settings.md)。

打开监控播放页或具体调查后，按左上角返回按钮回到列表；片段详情等弹层使用关闭按钮。
