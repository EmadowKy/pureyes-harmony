# 08-管理员控制台与用户管理

为了保障企业与安防系统的权限规范，Pureyes 设计了三级角色体系（超级管理员、管理员、普通用户）。具备管理员或超级管理员权限的账号可以访问【用户管理】控制台。首次启动会创建工号为 `admin` 的超级管理员，其密码由部署环境设置或在首次启动时随机生成。

---

## 1. 角色权限矩阵

系统根据用户角色自动开放对应的控制台权限：

| 权限 / 功能模块 | 普通用户 | 管理员 | 超级管理员 |
| :--- | :---: | :---: | :---: |
| 登录系统与个人信息修改 | 支持 | 支持 | 支持 |
| 搜索同组用户 / 查看通讯录 | 支持 (只读) | 支持 | 支持 |
| 查看【用户管理】控制台入口 | 不支持 | 支持 | 支持 |
| 创建新用户账号 | 不支持 | 支持 | 支持 |
| 重置/初始化用户密码 | 不支持 | 支持 | 支持 |
| 停用/启用用户账号 | 不支持 | 支持 | 支持 |
| 删除用户账号 | 不支持 | 支持 | 支持 |
| **调整与升级用户角色** | 不支持 | 不支持 | **支持** |

---

## 2. 用户管理控制台操作

进入【我的】页面，管理员账号可看到【用户管理】入口。

### 2.1 全局用户搜索与过滤
- 顶部提供实时搜索框，支持按工号、姓名、手机号快速检索系统中所有注册用户。
- 列表显示用户工号、姓名、当前角色标签、账号状态（正常/停用）。

### 2.2 创建新用户
1. 点击右上角【新增用户】按钮。
2. 填写新用户资料：
   - **工号**：必须全局唯一（如 `1008`）。
   - **姓名**：用户真实姓名（如 `王五`）。
   - **手机号**：可选填联络电话。
   - **初始密码**：必须由管理员设置，至少 6 位，不提供固定默认密码。
   - **初始角色**：新账号统一为普通用户；超级管理员可在创建后将其提升为管理员。
3. 点击保存提交。

### 2.3 账号启停用控制
- 在用户列表项上，点击【停用】按钮：
  - 账号状态立即变为停用。
  - 该用户的任何设备再次发起访问均会被直接拒绝并提示账号已被停用。
  - 历史登录凭据自动强制废弃。
- 点击【启用】按钮可恢复其登录权限。

### 2.4 密码重置与账号删除
- **初始化密码**：当员工忘记密码时，管理员可点击【初始化密码】，将该账号密码重置为初始密码。
- **删除账号**：管理员可清理离职人员账号。

---

> [!WARNING]
> 超级管理员是系统的最高权限拥有者，只有内置超级管理员可以将普通用户提升为管理员；系统不允许创建第二个超级管理员。请谨慎保管其凭据！
