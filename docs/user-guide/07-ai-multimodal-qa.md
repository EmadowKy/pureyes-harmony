# 07-工作区调查 Agent 与连续追问

工作区【问答】页是共享的调查工作台。每条调查线固定一组视频片段作为证据范围，记录各轮问题、工具执行过程与结论。已加入该小组的成员都能打开调查线并在上一轮结束后继续追问。

## 1. 建立调查线

1. 打开工作区【问答】页，点击【+ 新调查】（首次使用时可点击【开始第一条调查】）。
2. 从当前工作区选择至少一个相关片段，输入问题，在输入框下方选择个人或本小组的模型配置，点击【开始调查】。例如“画面中背黑包的人何时经过门口？”。一次最多选择 20 个片段。
3. 提交后进入调查工作台。调查列表展示标题、轮数、最近一轮状态与问题；打开任一记录可继续查看。

首次选定的片段就是该调查线的证据范围。后续追问自动沿用这组片段，不需要重新选择，也不会自动扩大到工作区的其他视频。每轮追问都可在输入框右下方选择本人的个人配置或当前小组的共享配置；没有可用配置时，先在【我的】→【模型 API】创建，或请组长建立小组配置。配置列表可在问答页刷新。历史轮次会显示提交时所用配置的名称；更改或删除配置不会改变运行中轮次的参数。

## 2. 查看执行过程和结论

运行中会显示当前阶段、已运行时间及进度。展开【执行记录】可按顺序查看各个分析步骤的名称、状态和摘要；展开单次步骤可查看用到的条件、找到的线索，以及可用的视频时间点。系统可能检索目标轨迹、画面内容、文字、人脸线索或再次核验画面；具体步骤取决于问题和视频内容。

需要对照不同片段时，Agent 也可在一次工具调用中读取最多 4 张来自所选视频的画面；执行记录为成功读取的画面分别提供视频和时间点入口，方便逐一核对。若部分画面截取失败，其余成功画面仍可用于核验。

结论按 Markdown 排版，支持标题、列表、表格、代码和链接。答案中形如 `[video:"1", time:"02:33"]` 的视频时间标记会显示为可点击的定位入口；点击后打开对应片段并跳到指定时间。工具结果和模型回答是调查线索，关键事实应结合原视频核对。

工具记录展示的是经过整理的公开参数与观察结果，不会展示模型内部思考内容。未产生工具调用的轮次不会出现工具链。

## 3. 组员追问与上下文

上一轮结束后，任何已加入该小组的成员都可在同一调查线中输入追问。运行期间，提问者和其他组员都只能查看进度与执行记录，不能再提交新消息；如需改问，先点击【停止本轮】，随后追问。

追问会带上固定的视频证据范围，以及从已保存轮次重建的有限上下文：优先纳入最近的提问、**已完成**的结论与工具观察，并按关联程度选取部分更早的轮次。较早内容可能只有简短索引；受上下文长度限制，并非整条历史逐字进入模型。停止或失败的轮次会保留记录，但不会被当作已确认结论。

已完成轮次中带时间点的工具线索也会按视频归档。后续追问会按当前问题取回部分相关线索及其来源，帮助 Agent 继续核验。人脸、目标、画面语义和文字索引都是候选线索；单帧描述仍需复核，不能直接据此认定不同视频里的人或事件相同。

## 4. 停止、失败和等待

任一已加入小组的成员都能停止正在运行的一轮；该轮显示【已停止】，调查线随即可继续追问。失败的最新一轮提供【重新尝试这一问】，也可重新组织问题再追问。运行中超过约 90 秒没有新进度时，界面会给出提示，这只是提醒，并不表示任务已经失败。

运行超时或异常会将本轮标记为失败，之后可重试或继续提问。调查与各轮记录保存在工作区中，重新打开后仍可查看历史状态、答案和执行记录。
