# 个人中心与模型配置

【我的】用于查看资料、处理邀请、修改密码、设置模型配置和打开[使用说明](http://116.62.178.139/)。进入具体功能后，全局底栏会收起；点击左上角返回按钮回到【我的】首页。

## 个人信息与账号

在【个人信息】查看工号、姓名和手机号，也可更新姓名、手机号和头像。修改登录密码请进入【账号安全】，步骤见[账号登录与安全](03-authentication.md)。

【我的消息】显示收到的小组邀请，可接受或拒绝；组长发送的邀请也会在这里显示。新建小组见[小组协作](04-group-collaboration.md)。

## 模型 API 配置

进入【我的 → 模型 API】，可以创建多个命名配置。填写配置名称、API 密钥、接口地址和模型名称；编辑时 API 密钥留空表示保留原值，已有密钥不会回显。

- **个人配置**：本人创建、修改、删除和使用。
- **小组配置**：由小组长为自己创建的小组设置；该小组的成员都可在调查问答中选择，小组长负责修改和删除。

提交问题前，在问答输入框下方选择本轮要用的配置。删除配置后无法再用于新问题，已提交的轮次不会因此改变。如何提问见[调查问答](07-ai-multimodal-qa.md)。

### 配置一项可用的视觉模型

1. 选择【个人配置】或【小组配置】；后者只对当前小组的组长开放。
2. 给配置填写便于辨认的名称，例如“日常视频调查”，再填写服务商提供的 API Key、兼容接口地址和准确的模型名称。
3. 点击【保存】，回到调查页刷新可用配置并选择它。

调查需要模型能够处理图像与工具调用；仅支持文字的模型不适合核验视频画面。页面上的示例模型名和地址并不是固定要求。Key 留空仅适用于编辑已有配置，新建时必须提供；组员可以使用共享配置，但看不到组长保存的密钥。

| 情况 | 操作建议 |
| --- | --- |
| 找不到小组配置选项 | 确认已选择小组且自己是组长；管理员身份不自动等于所有小组的组长。 |
| 调查页没有刚保存的配置 | 刷新配置列表，确认当前工作区属于该小组。 |
| 模型返回鉴权、欠费或不存在错误 | 核对服务商控制台、接口地址和模型名；修正后重新尝试失败问题。 |
| 想比较两个模型 | 保存为两个命名配置，并在各轮提交前选择；无需反复覆盖同一配置。 |

## 其他入口

【新建小组】用于创建团队；【用户搜索】或【用户管理】因账号权限不同而显示。点击【使用说明】会尝试用浏览器打开在线文档。需要离开账号时，点击【退出登录】。
