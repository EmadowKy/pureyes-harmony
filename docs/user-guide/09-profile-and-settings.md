# 09-个人中心与系统设置

【我的】模块是用户管理个人资料、查看安全状态、调整大模型 API 配置、客户端设置以及访问管理控制台的总入口。

---

## 1. 个人资料卡片

在【我的】页面顶部，呈现精致的个人资料卡片：

- **用户头像**：显示默认系统头像或自定义上传的头像图片。
- **姓名与角色勋章**：清晰标示当前登录用户的姓名以及角色（如：`超级管理员` / `管理员` / `普通用户`）。
- **工号与手机号**：展示用户绑定的唯一工号与联系电话。
- **编辑资料**：点击头像旁边的编辑图标，可更新姓名、手机号以及个人头像。防误清空机制保证未填项不会覆写原有资料。

---

## 2. 大模型 API 设置

系统支持用户配置个人或企业专属的视觉大语言模型 API，进入【我的】->【大模型 API 设置】即可进行自定义配置：

- **API 密钥**：输入您的多模态大模型服务 API 密钥。
- **接口基础地址**：输入大模型服务接口的基础地址（如兼容 OpenAI 格式或各主流大模型厂商的 API 接口 URL）。
- **大模型名称**：指定要使用的大模型名称。

设置完成后点击保存，系统在进行工作区多模态视觉问答时，将自动优先使用您配置的大模型接口进行推理。

---

## 3. 系统功能菜单划分

【我的】页面采用了清晰内聚的模块化分组：

```mermaid
graph TD
    ProfilePage[【我的】页面菜单功能划分] --> Section1[个人信息与编辑]
    
    ProfilePage --> Section2[账号安全与协作]
    Section2 --> Security[账号安全: 修改密码]
    Section2 --> Messages[我的消息: 团队通知]
    Section2 --> LLMConfig[大模型 API 设置: 密钥/地址/模型]
    Section2 --> GroupCreate[新建小组: 安防单元]
    Section2 --> UserAdmin[用户管理/搜索: 管理员专属]

    ProfilePage --> Section3[外观与通用设置]
    Section3 --> Appearance[外观设置: 浅色/深色/随系统]
    Section3 --> About[关于软件: 版本检查与系统符号]
    
    ProfilePage --> Logout[退出登录: 安全销毁凭据]
```

---

## 4. 外观与系统符号设置

- **鸿蒙系统符号**：应用全面适配鸿蒙系统原生矢量系统符号资源，图标大小、色彩随深色/浅色主题智能自适应变化。
- **语言与国际化**：支持中文简体与英文系统语言自适应。
- **版本检查**：在【关于软件】中可一键检测更新，确保客户端始终处于最新稳定版本。
