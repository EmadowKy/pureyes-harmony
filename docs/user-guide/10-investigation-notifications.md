# 调查通知与桌面小部件

通过系统通知、桌面【清眸调查】服务卡片，以及支持设备上的闪控窗，可以在调查页之外查看任务状态。调查在服务器运行，手机负责同步与展示；停止任务请进入调查点击【停止本轮】。

## 1. 开启通知

第一次发起调查时允许清眸发送通知。此前拒绝授权时，可在工作区问答页点击【开启通知】，或在系统设置中允许清眸通知；不需要重做已经提交的问题。

- 运行时通知展示阶段、已运行时间和工具步骤数，多项任务独立更新。
- 完成、失败或停止时，在应用观察到状态变化后发送结果通知。
- 点击通知会经过登录校验，再返回对应工作区的调查。
- 调查通知展示阶段、用时和工具步骤数，隐藏问题、标题、答案、视频和密钥。

运行期间，系统还会显示数据传输后台任务入口。后台同步条件见[后台与网络](#_4-后台与网络限制)。

## 2. 添加桌面服务卡片

在支持服务卡片的鸿蒙桌面，打开清眸应用图标的卡片入口，选择【清眸调查】，按桌面提供的方式添加。具体入口名称因设备与系统版本而异。应用提供 2×2 和 2×4 两种尺寸；若桌面暂未识别卡片，可重新打开应用后查看可添加项。

![桌面调查卡片展示调查的完成状态和计数](/screenshots/20260929/35-desktop-widget.webp)

无运行任务时，卡片显示最近的调查记录和完成计数。

## 3. 看进度、切任务、回到调查

| 卡片状态或操作 | 含义 |
| --- | --- |
| 调查中 | 小鸮查看线索，显示阶段、用时、步骤数；优先展示运行任务。 |
| 已完成／失败／停止 | 展示最近一次同步的终态，点击可核对对应调查。 |
| 无运行任务 | 展示调查总数、已完成数与最近记录，按每条调查的最新轮次统计。 |
| 左右箭头 | 切换当前可查看的任务；不同卡片可独立选择。 |
| 中间内容 | 验证登录状态后进入对应工作区与调查。 |
| 右上角【↻】 | 手动请求最新状态并刷新卡片。 |
| 底部同步时间 | 最近一次从服务器获取任务状态的时间。 |

卡片展示调查标题、阶段、用时与步骤数。标题可在调查列表中修改，建议使用便于辨认且不含敏感身份信息的名称。视频、人脸抓拍和答案留在应用内查看；退出登录会清空卡片与调查通知。

## 4. 后台与网络限制

应用在前台、或系统允许连续后台任务期间同步服务器状态；不需要停留在调查详情。没有运行任务后停止连续后台任务。网络断开、系统取消后台任务、应用被强制关闭或通知被禁用时，展示和提醒都可能延迟。

如果同步时间长时间没有变化，打开应用检查网络与登录状态，再点击卡片刷新。服务器任务继续独立运行；重新同步后可查看进度与结果。失败任务的重试、修改标题与删除记录操作见[调查问答](07-ai-multimodal-qa.md)。

## 5. 闪控窗与闪控球

闪控适用于支持该能力的 HarmonyOS 7 设备。在工作区【问答】页面点击【开启闪控】，按系统提示授权；从某条调查详情开启时，优先展示该调查。开启后可以离开清眸，在其他应用上方查看进度。

| 操作与状态 | 显示或行为 |
| --- | --- |
| 调查进行中 | 显示当前阶段、工具步骤数和已运行时间；时间在两次同步之间继续走动。 |
| 多项调查 | 右上角显示当前位置，使用【上一项】【下一项】切换；运行中任务排在前面。 |
| 收起与展开 | 使用系统提供的窗口控件收起为闪控球，再点击闪控球展开。窗口拖动、贴边及侧边栏行为由设备系统管理。 |
| 【查看】 | 返回当前所选调查所在的工作区，核对问题、工具记录和结论；返回后关闭闪控。 |
| 已完成、失败或停止 | 保留该项的结束状态和最终用时，等待用户查看，不主动抢占当前应用。 |
| 同步中断 | 显示上次同步的进度，耗时停止增长；返回清眸检查网络后恢复同步。 |
| 关闭闪控 | 通过系统关闭控件，或在清眸点击【关闭闪控】。关闭只停止窗口展示，不取消服务器调查。 |

闪控窗与闪控球仅显示运行阶段、步骤数、耗时和任务位置，不显示调查标题、问题、答案、视频或人脸。退出登录会清空内容并关闭窗口；再次登录后需主动开启。追问产生新一轮任务时，窗口继续跟随当前所选会话。

设备不支持或权限未开启时，页面会说明原因，可继续使用应用内进度、任务通知与桌面小部件。闪控与这些入口共用任务状态，其后台更新条件同[后台与网络](#_4-后台与网络限制)。
