# 调查通知与桌面小鸮

调查需要离开当前页面等待时，可通过系统通知和桌面【清眸调查】服务卡片查看最近同步状态。调查本身在服务器运行；手机负责同步和展示，关闭手机界面不等于停止服务器任务。

## 1. 开启通知

第一次发起调查时允许清眸发送通知。此前拒绝授权时，可在工作区问答页点击【开启通知】，或在系统设置中允许清眸通知；不需要重做已经提交的问题。

- 运行时通知展示阶段、已运行时间和工具步骤数，多项任务独立更新。
- 完成、失败或停止时，在应用观察到状态变化后发送结果通知。
- 点击通知会经过登录校验，再返回对应工作区的调查。
- 普通调查通知不显示问题、标题、答案、视频和密钥。系统后台任务入口由系统控制，不等于永远不可移除的普通通知。

授权通知不会保证应用被强制关闭后仍能接收完成提醒。当前使用状态轮询，不是服务器云推送。

## 2. 添加桌面服务卡片

在支持服务卡片的鸿蒙桌面，打开清眸应用图标的卡片入口，选择【清眸调查】，按桌面提供的方式添加。具体入口名称因设备与系统版本而异。应用提供 2×2 和 2×4 两种尺寸；若桌面暂未识别卡片，可重新打开应用后查看可添加项。

## 3. 看进度、切任务、回到调查

| 卡片状态或操作 | 含义 |
| --- | --- |
| 调查中 | 小鸮查看线索，显示阶段、用时、步骤数；优先展示运行任务。 |
| 已完成／失败／停止 | 展示最近一次同步的终态，点击可核对对应调查。 |
| 无运行任务 | 展示调查总数、已完成数与最近记录；按每条调查的最新轮次统计，不是每轮问答的总数。 |
| 左右箭头 | 切换当前可查看的任务；不同卡片可独立选择。 |
| 中间内容 | 验证登录状态后进入对应工作区与调查。 |
| 右上角【↻】 | 手动请求最新状态并刷新卡片。 |
| 底部同步时间 | 判断当前内容的新鲜程度；它不是任务开始或结束时间。 |

这里显示的不是预计完成百分比。卡片含调查标题，标题可能来自首问；桌面可被旁人看到，不应在标题中填写敏感身份信息。卡片不展示视频、人脸抓拍或答案。退出登录会清空卡片与调查通知。

## 4. 后台与网络限制

应用在前台、或系统允许连续后台任务期间同步服务器状态；不需要停留在调查详情。没有运行任务后停止连续后台任务。网络断开、系统取消后台任务、应用被强制关闭或通知被禁用时，展示和提醒都可能延迟。

如果同步时间很久没变，先打开应用确认网络与登录状态，再点击卡片刷新。卡片缓存不代表调查已经停止；真正停止一轮请进入会话点击【停止本轮】。失败任务的重试和会话标题／删除操作，见[调查问答](07-ai-multimodal-qa.md)。
