# 真实监控视频：多视频调查测试用例

本组用例使用 UCF-Crime 的真实监控录像，不使用剧情片、广告或合成视频。每题在同一工作区导入多段视频，问题及追问都针对该工作区。UCF-Crime 的片段来自**不同的监控场景**，可测试跨视频检索、比较和证据归纳；不能用它们测试同一人跨摄像头追踪。文末另列同场景跨机位数据。

## 视频及标注来源

- 视频：[UCF-Crime 官方下载页](https://www.crcv.ucf.edu/research/real-world-anomaly-detection-in-surveillance-videos/)；页面提供分包下载。请在测试集目录中按下表原始文件名找到 MP4。
- 标注：官方页面的 *Temporal Annotation for Testing Videos*；可用[公开文本镜像](https://github.com/INSEA-99/UCF-Crime-Anomaly-Detection/blob/main/Test_Annotation.txt)核对文件名、事件类别和异常帧区间。该镜像在原有标注后增加总帧数列，下表仅依赖类别和区间。
- **导入前统一重命名**为 `A.mp4`、`B.mp4` 等。原文件名和上层类别目录包含答案，不能直接作为 Agent 可见的视频名称或描述。也不要把本文件、标签或标注区间送入被测 Agent 的上下文。
- 区间为视频内**帧号**，不是秒数；`-1 -1` 表示没有标注异常。播放时用 `ffprobe -v error -select_streams v:0 -show_entries stream=avg_frame_rate -of default=noprint_wrappers=1 <视频>` 读取各视频帧率，再计算 `秒数 = 帧号 / 该视频帧率`。允许播放器定位和标注边界有小幅偏差。

## 用例 1：三段视频中找异常，并区分事件

| 导入名 | 原始测试集文件 | 标注类别 | 异常帧区间 |
| --- | --- | --- | --- |
| A | `RoadAccidents/RoadAccidents123_x264.mp4` | 交通事故 | 130–210 |
| B | `Shooting/Shooting007_x264.mp4` | 枪击 | 45–165 |
| C | `Testing_Normal_Videos_Anomaly/Normal_Videos_015_x264.mp4` | 正常 | 无 |

**第一轮问题：**“这三段录像中，哪几段有需要关注的异常？分别是什么？请列出视频和画面依据。”

**预期：**A 有交通事故，B 有枪击事件，C 不应被标成异常。答案要分别引用 A、B 的画面，不得把两段不同录像编造成同一事件。

**追问：**“分别定位异常出现的片段；C 有没有同类事件？”

**预期：**A 约在第 130–210 帧，B 约在第 45–165 帧；C 没有被标注的异常。若可见画面不足以证明具体行为，应说明不确定，不要从文件名猜测。

## 用例 2：多段同类事件，比较重复出现次数

| 导入名 | 原始测试集文件 | 标注类别 | 异常帧区间 |
| --- | --- | --- | --- |
| A | `Shoplifting/Shoplifting007_x264.mp4` | 商店行窃 | 550–760；4630–4920 |
| B | `Shoplifting/Shoplifting027_x264.mp4` | 商店行窃 | 1080–1160；1470–1710 |
| C | `Shoplifting/Shoplifting005_x264.mp4` | 商店行窃 | 720–930 |

**第一轮问题：**“三段录像里，哪些有两段相互分开的异常片段？哪一段只有一次？请分别核验，不要按文件数量计数。”

**预期：**A、B 各有两段标注异常；C 一段。这里的“次数”只指标注区间数，不能推断为不同的人或不同案件。

**追问：**“把 A 和 B 的第二段异常分别定位出来，第一段和第二段之间是否一直在发生异常？”

**预期：**A 第二段为 4630–4920 帧，B 第二段为 1470–1710 帧；两个区间之间没有连续的**已标注异常**。不能由此断言中间绝对没有任何可疑动作。

## 用例 3：不同事件类型和两段式时间线

| 导入名 | 原始测试集文件 | 标注类别 | 异常帧区间 |
| --- | --- | --- | --- |
| A | `Burglary/Burglary021_x264.mp4` | 入室盗窃 | 60–200；840–1340 |
| B | `Arson/Arson011_x264.mp4` | 纵火 | 150–420；680–1267 |
| C | `Testing_Normal_Videos_Anomaly/Normal_Videos_042_x264.mp4` | 正常 | 无 |

**第一轮问题：**“三段录像各有什么异常？有哪些是不同类型、却都分成两段出现的？”

**预期：**A 标为入室盗窃，B 标为纵火，二者各有两段异常区间；C 未标注异常。具体“入室”“纵火”措辞要结合可见画面审慎使用，标注类别不能代替视觉证据。

**追问：**“A、B 各自第二段发生在什么位置？能否判断 A 和 B 是同一批人或有因果关系？”

**预期：**A 为 840–1340 帧；B 为 680–1267 帧。这是两段独立监控录像，标注不支持同人或因果判断，应明确证据不足。

## 同场景跨机位补充：WILDTRACK

[WILDTRACK 官方页面](https://www.epfl.ch/labs/cvlab/data/data-wildtrack/)提供七个机位的视频及同步帧和逐帧人员标注；摄于真实室外场景，机位视野有重叠。可选 Camera 1、2、3 的同一时间段导入，测试“不同机位的人数不能简单相加”“同一目标在多机位上的证据应交叉核验”。**目前不把某个具体人的身份、颜色或人数写成标准答案**：必须下载官方标注并人工核对所选时刻与机位后才能制作这类金标准题。此项是下一轮跨机位测试素材，不能用上述 UCF-Crime 的独立录像替代。

## 使用与评分

1. 每题新建工作区，只导入表内视频；同一题的追问沿用原会话和视频范围。
2. 检查工具记录：Agent 是否实际访问所有相关视频、是否在追问时重新定位相应区间、是否为不同视频分别给出证据。
3. 类别、异常区间数、对应视频、追问中的区间必须正确；帧到秒的显示依据各视频实际帧率，允许合理误差。
4. **不要把数据集标签当作肉眼已确认的细节。**以上预期来自公开标注，尚未逐帧观看原视频；人物衣着、动作细节、跨视频同一身份和具体因果均不在金标准内。测试前最好由一名组员下载并复核目标片段，记录实际播放器时间戳。
